# نظام إدارة مناي ڤيردي

نظام إدارة متطور يدعم ثلاث لغات مع مشاركة البيانات السحابية في الوقت الفعلي.

## الميزات الرئيسية

- 🌐 دعم ثلاث لغات: العربية، الإنجليزية، الإيطالية
- ☁️ مشاركة البيانات السحابية عبر Firebase
- 📊 إدارة الواردات والصادرات
- 👥 إدارة الموظفين
- 📝 إدارة الملاحظات
- 🔒 نظام تسجيل دخول آمن
- 📱 تصميم متجاوب

## روابط النظام

- [الصفحة الرئيسية](./index.html)
- [تسجيل الدخول](./login.html)
- [لوحة التحكم](./modern-dashboard.html)

## بيانات تسجيل الدخول

- مدير: `admin` / `admin`
- مستخدم عادي: `mani` / `mani`
- مستخدم متقدم: `iraq` / `iraq`

## التقنيات المستخدمة

- Frontend: HTML5, CSS3, JavaScript ES6
- Database: Firebase Realtime Database
- Styling: Modern CSS with Glassmorphism effects
- Icons: Font Awesome
- Fonts: Google Fonts (Cairo)

## الإصدار

الإصدار الحالي: 2.0 - دعم Firebase للمشاركة الحقيقية

## كيفية الاستخدام

1. افتح الرابط: http://localhost:8090
2. أو استخدم GitHub Pages (قد يحتاج وقت للتحديث)
3. سجل الدخول بأحد البيانات المذكورة أعلاه
4. استمتع بإدارة البيانات مع المشاركة الفورية!
