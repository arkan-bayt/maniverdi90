نظام إدارة حديث ومتعدد اللغات مصمم خصيصاً لشركة ماني فيردي. يتميز بواجهة مستخدم عصرية وسهلة الاستخدام مع دعم كامل للغة العربية والإنجليزية والإيطالية.

## 🚀 المميزات الرئيسية

### 🔐 نظام المصادقة
- تسجيل دخول آمن مع أدوار مختلفة
- ثلاثة مستويات من المستخدمين: مدير، مستخدم ممتاز، مستخدم عادي

### 📊 إدارة البيانات
- **📥 إدارة المستوردات**: تتبع جميع المنتجات المستوردة مع الأسعار والتواريخ
- **📤 إدارة المصدرات**: متابعة عمليات التصدير والمبيعات
- **👥 إدارة الموظفين**: معلومات الموظفين والرواتب وتواريخ التعيين
- **📝 إدارة الملاحظات**: نظام ملاحظات مرن مع فئات وأولويات مختلفة
- **👤 إدارة المستخدمين**: (للمدير الممتاز فقط) إضافة وتعديل حسابات المستخدمين

### 🌍 الدعم متعدد اللغات
- العربية (مع دعم RTL)
- الإنجليزية
- الإيطالية

### 🎨 واجهة المستخدم العصرية
- تصميم متجاوب يعمل على جميع الأجهزة
- Material-UI للمظهر الحديث
- رسوم بيانية وإحصائيات تفاعلية
- ألوان وأيقونات جذابة

### ⏰ تتبع التوقيت الدقيق
- حقول التاريخ والوقت في جميع العمليات
- تسجيل تلقائي للتوقيت عند الإضافة والتعديل

## 🛠 التقنيات المستخدمة

### Frontend
- **React** 18.2.0 - مكتبة JavaScript للواجهات
- **Material-UI** 5.13.6 - مكونات UI حديثة
- **React Router** - للتنقل بين الصفحات
- **Axios** - لطلبات HTTP
- **i18next** - للترجمة متعددة اللغات

### Backend
- **Node.js** - بيئة تشغيل JavaScript
- **Express** - إطار عمل خادم الويب
- **CORS** - للسماح بالطلبات من مصادر مختلفة
- **Mock Database** - قاعدة بيانات وهمية للتطوير

## ⚡ التشغيل السريع

### المتطلبات
- Node.js v18 أو أحدث
- npm أو yarn

### خطوات التشغيل

1. **استنساخ المشروع**
```bash
git clone https://github.com/your-username/mani-verdi-management.git
cd mani-verdi-management
```

2. **تثبيت التبعيات**
```bash
# تثبيت التبعيات الرئيسية
npm install

# تثبيت تبعيات الخادم
cd server && npm install

# تثبيت تبعيات العميل
cd ../client && npm install
```

3. **تشغيل المشروع**
```bash
# العودة للمجلد الرئيسي
cd ..

# تشغيل الخادم والعميل معاً
npm run dev
```

4. **فتح التطبيق**
- واجهة المستخدم: http://localhost:3001
- API الخادم: http://localhost:5001
